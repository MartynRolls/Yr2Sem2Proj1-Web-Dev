My Web Technologies

Top 5 web technologies that I use:
  1. Programming Language - to define & create a website using HTML, CSS, and Javascript; languages able to be interpreted by any modern web browser.
  2. Code Editor - to write the program with syntax highlighting, auto-complete, etc. Quality of life features absent from a normal text editor. e.g. VSCode.
  3. Web Frameworks - to be able to quickly create websites using pre-defined classes, attributes, code, etc. e.g. this website was made using Bootstrap, a framework for CSS.
  4. Browser - to review changes and updates made to the code and to review documentation online. e.g. Google Chrome, Firefox, Edge, etc.
  5. Web Hosting - to publish the website online for others to visit and see. I've been able to do this on GitHub, but can also be done with other services using DNS.
